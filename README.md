# NEXUS OS

A browser-based desktop environment prototype. This first milestone focuses on the core desktop experience.

## Included in Preview 0.1

- NEXUS boot screen and local guest session
- Desktop shortcuts and app launcher
- Movable, minimizable, maximizable, and resizable app windows
- Files home screen, Notes with local autosave, Settings, Calculator, Terminal, and About
- Theme and accent color preferences saved locally
- Clock and a recoverable system error overlay
- Responsive layout for desktop and mobile browsers

## Run locally

Open `index.html` in a modern browser. No build step, server, API key, or paid service is required.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save. GitHub Pages will publish the desktop.

## Notes

NEXUS is a browser-based desktop experience, not a replacement for a device operating system. Browser storage is separate from physical disk storage. The app store, installable app packages, and adaptive virtual storage are planned for a later milestone.
